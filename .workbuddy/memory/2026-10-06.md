## ⚠️ 重要：git push 挂死的根因与解法
- 现象：push 长时间无输出挂死/被 SIGTERM，偶发 remote rejected (Internal Server Error)。
- 根因（GIT_TRACE 抓到）：凭据助手 `credential.helper-selector` 在 push 后执行 store 时运行 `git config --system -e` 打开交互式编辑器，无人值守环境永久挂起。
- 解法：推送时禁用凭据助手链，直接用 remote URL 内嵌 token：
  `git -c credential.helper= -c http.version=HTTP/1.1 push origin main`
- 代理现状：~/.gitconfig http.proxy=127.0.0.1:7897（存活）；环境变量代理 127.0.0.1:17824（已死）。git 走配置文件的 7897。
- 今后该项目推送一律加 `-c credential.helper=`，避免挂起。
